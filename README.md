# 🏥 MedTrack India

MedTrack India is an intelligent healthcare resource discovery platform designed to help users find suitable hospitals and emergency healthcare facilities across India.

## 🚀 Features

- 📍 GPS-based hospital discovery
- 🏥 Hospital search by city, state, specialty and facility
- 🗺️ Interactive hospital map
- 🛏️ Hospital bed and ICU availability
- 🚨 Emergency Mode
- 🚑 Ambulance availability and navigation
- 🩸 Blood availability search
- 🤖 Intelligent hospital recommendation
- ⭐ Hospital ratings
- ✅ Verified hospital information
- ⏱️ Data freshness and last-updated information
- 📱 Responsive web interface

## 🎯 Objective

Unlike a traditional hospital directory, MedTrack aims to answer:

> "Which suitable hospital can actually help me now?"

The platform combines location, hospital resources, emergency capabilities and travel information to help users make faster healthcare decisions.

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- Leaflet.js
- OpenStreetMap
- Browser Geolocation API
- Google Maps Navigation
